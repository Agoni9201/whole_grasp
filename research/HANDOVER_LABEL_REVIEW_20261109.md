## 先核对一轮，不必一次标完

1. 选“训练录像1 · 19:54:49”。选择定位下拉里的第一个“P 握住后轻拉”，页面会跳到原P按键当时；可点退1秒向前核对实际动作。
2. 播放，必要时切0.5倍、退1秒、逐帧。原P提示可能晚于实际动作，往前后看，不照着它直接接受标签。
3. 找到一段能确认的动作，暂停，点“开始”；到这段动作结束处，点“结束”。
4. 选动作类别，点“保存这一段”。例如先握住不拉标H，接着明确轻拉标P，完全松开以后标U；分不清的边界留空即可。
5. 先完成一轮H/P/U，之后再标T和一段N。保存后可以直接告诉助手已完成，助手从项目文件读取标注，不用你手抄秒数或上传截图。

原按键提示只用于导航，不会自动进入已确认标注。没有标过的时段默认UNKNOWN，不当负例。标注互相重叠时页面会拒绝，调整边界或删除冲突段再保存。

## 类别怎么选

| 标注 | 你需要确认的事 |
| --- | --- |
| N 完全不接触 | 手没有接触物体或机械臂；手靠近没碰可写备注区别于手远离背景 |
| H 握住但不拉 | 这一段确实握住了，但没有轻拉 |
| P 握住后轻拉 | 结合本人操作记忆能确认有接取轻拉；单看见握住不能确定轻拉时，选H或X |
| T 碰一下/推一下 | 没有接取轻拉的短碰/推；可包含紧邻的明确无轻拉背景，供短窗口模型看上下文 |
| U 完全松手后 | 已松开物体和机械臂；手仍在画面中也可标U，不要求已撤出视野 |
| A 碰/摇机械臂 | 接触机械臂本体的扰动单独标，不能混成握物接取 |
| X 不确定 | 看不清、记不准或接触/受力边界不确定，不直接用于训练 |

动作不用标准化，开始/结束不用强求毫秒准确。优先标明确核心区间；过渡留空。录像不能独立测得拉力、支撑比例或证明已经接稳，所有标注都只是动作/接触类别。

## 保存和数据分组

标注自动保存为`artifacts/handover_label_review_20261109/annotations/<会话ID>.json`。每次编辑保留上一版`.json.bak`；原始samples、视频和元数据不改。JSON保存原始SHA256、真实抓取group、train/test来源、帧索引与接收时钟、人工标注来源、原始FAULT/在线基线/内环故障标记。

前4段为grasp01训练材料；最后一段21:43:16为新抓取的测试候选，不能混入训练或用来反复选阈值。页面只显示录像和原按键，不显示力矩曲线，减少用输入信号给自身制造标签的风险。

灰/红色状态说明中的FAULT不能通过标注抹掉；动作可以被人工确认，状态有效性仍要另作判断。21:40候选缺原在线R/B，使用的是来源单列的离线参照，页面不伪造在线准备成功。

后续先审核标注、排除不确定边界和跨标签的因果窗口，再生成训练样本。短碰等负类窗口可按“整个窗口都明确不是接取轻拉”的目标合并相邻已确认负状态；H单独保留，不偷换成NO_CONTACT。不得将相邻重叠窗口随机分进训练和测试。模型训练与真实开夹验证尚未执行。
