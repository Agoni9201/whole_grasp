**group是一次真实物理抓取的编号。** 同一次抓取后程序退出再用--held继续，仍使用原group和split。新开日志/换编号本身不增加物理独立性。不能把同一物理抓取的连续记录分到训练和测试；启动脚本会拒绝已存在于另一分组目录的同一group，但无法替代操作者正确编号。

## 命令

确认旧控制程序已退出、机械臂稳定持物；已激活grasp_yolo26并启用can0。

```bash
bash scripts/collect_handover_shadow.sh Right --held --group grasp01 --split train
```

本批停车并完成采集后Q退出。将物体放回可抓取位置、满足原完整抓取流程的启动条件，再运行下一批；**下面不带--held，会执行初始张爪与重新抓取**，不能在仍悬空夹着物体时直接照跑：

```bash
bash scripts/collect_handover_shadow.sh Right --group grasp02 --split train
```

后续根据上表分别换group与split。测试批例如下面，同样在物体已回桌、允许重新抓取的条件下运行：

```bash
bash scripts/collect_handover_shadow.sh Right --group grasp05 --split test
```

若已经用其他流程完成一次新的抓取，可在其退出后给该新批次命令添加--held；它只表示跳过重新抓取，不意味着换了物理抓取批次。若可用时间临时缩短，优先保住至少一批validation和一批test，记录缺失与实际动作次数，不挪测试数据凑训练数量。

## 每批都按同一张动作表

启动→腕部递送自动停车或全局窗口S人工停车→FUSION_WAIT_BASELINE→R圈露出物体，Enter确认→手完全离开物体与ROI时B→FUSION_WAIT_TAKE。各批都重建基线；全局窗口识别标签应为Right。

键盘标记是粗事件，**动作与按键的误差留给录像复核**，不是精确真值。能由另一人按键最好；独自采集时先标记再做固定动作，保留动作前后不确定边界。原有N/P/U不能直接覆盖错位帧；握住不拉用H单独保存。

| 顺序 | 动作及按键 | 每批数量 |
| --- | --- | --- |
| 1 | N：手完全离开，全程不碰物体 | 60秒 |
| 2 | H：握住不拉约3秒；P：轻拉约2秒；U：完全松手并移开，等10秒 | 重复6次；保留轻拉前后过程与残余 |
| 3 | T：轻碰/轻推一下后立即完全松手；U：移开等10秒 | 重复6次；覆盖容易和轻拉混淆的动作 |
| 4 | N：手靠近物体但不接触，稍停后撤回；仍保留全过程 | 重复3次；不要把实际接触标成N |
| 5（时间允许） | 正常握物出现自然遮挡、不同轻拉方向的片段；同样H/P/U | 单独备注，不因看不见就删录像 |

不要追求力矩“必须够大”，不靠拧动末端凑正例。若进入FUSION_FAULT，本次许可已失效，松手、停止本轮动作并Q退出；原始数据仍在，保留故障片段，不继续当作正常有效交接试次。后续同抓取恢复采集仍沿用同group/split。现有姿态门限、MIT控制律与故障锁存没有因为采集而放宽。

## 必须带走的数据与采后检查

新分组目录：`logs/handover_dataset_20261109/<split>/<group>/`。完整抓取还会在其下建立外层运行目录；每个融合会话位于某个`handover_fusion/<时间>/`。

- `metadata.json`：group/split、相机序列号/模式、配置、无模型、未核实标签声明。
- `samples.jsonl`：七轴原始力矩/电流、q/原始dq、逐轴时标、基线、**精确停车hold_q和漂移门限**、控制/夹爪状态、策略状态及按键。
- `global/global_rgb.avi`＋`observations.jsonl`：原始全局RGB、逐帧时标与视频索引；新增**所有手的关键点与手侧置信度**，包括被过滤掉的手，方便离线改变视觉判据重算。全局仍RGB-only，无米制XYZ。
- `wrist_rgb/`：已有约10Hz腕部RGB保存；本轮没有新增腕部完整深度录像。原始腕部抓取/跟随RGB-D诊断与全局RGB离线回放能力应区分。
- `capture_snapshot/`：带group的新采集在启动观察流前自动拷贝采集/判据/手检测关键源码、当前配置与标定JSON，manifest保存来源路径和SHA256；不会改原文件。不是完整运行环境或模型权重备份。

各批退出后可不接机器人执行：

```bash
python tools/check_handover_dataset.py --root logs/handover_dataset_20261109
```

它汇总基线、原始七轴条数、视频/关键点、粗标签事件、故障前后原始数据及跨分组group冲突，不把“文件齐了”宣称成“已达到训练质量”。有空日志/缺视频/无基线时优先趁设备可用补采。同一动作连续几百帧不算几百次动作。

尽量备份整个采集根目录，而非只拷曲线或samples；保存采集代码/配置快照。后续离线按录像核对可确认动作区间，不确定的受力起点保持unknown；剔除跨边界的1秒窗口，按物理抓取分组训练/调参/测试。原始故障段可用来分析、重算假设，但不能绕过状态/姿态限制当作有效释放正例。

离线先比较全七轴/单J2/去J4与规则，再把视觉、撤回、残余和姿态检查放回状态机回放。报告误候选、漏检、延迟、拒判；真实接住/掉落与开夹后效果仍需要之后留一次短时真机验证，不能由不开夹的录像证明。

本次准备没有操作相机/CAN/机械臂、修改控制律/门限、训练或加载真实模型。验证与证据见[准备记录](../artifacts/handover_collection_prepare_20261109/README.md)。
