# MediaPipe Hand Landmarker model

- Source: `https://storage.googleapis.com/mediapipe-models/hand_landmarker/hand_landmarker/float16/1/hand_landmarker.task`
- SHA-256: `fbc2a30080c3c557093b5ddfc334698132eb341044ccee322ccf8bcf3607cde1`
- Runtime: MediaPipe Tasks `HandLandmarker` in VIDEO mode.

The model detects human-hand landmarks. RealSense aligned depth is sampled at
the palm landmarks to report a metric position in the color optical frame.
